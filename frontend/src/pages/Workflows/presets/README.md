# 工作流预设

工作流页面的“预设”文件夹和新建编辑器共用 `index.ts` 中的 `workflowPresets` 登记表。

后续新增预设时，将定义放在本目录，并在登记表中提供唯一 ID、名称、说明、应用依赖、构建函数和加载失败提示。列表入口和编辑器加载会自动接入，无需在页面顶部增加单独的预设按钮。

构建函数返回尚未保存的工作流草稿，使用预设后仍由用户编辑并创建自己的工作流。现有公众号图文预设复用 `@/lib/wechatParallelWorkflow` 中的构建函数。

`contentSuite.ts` 将三个独立预设组合为一个总预设，共用 `writer` 与启动选题。公众号支线保留原有文件路径（插图 Markdown 和排版 HTML 需与原稿同目录）；图文、短视频支线分别写入 `image-text/` 和 `short-video/`，并同步重写节点引用、文件契约和提示词中的路径。修改独立预设的目录约定时，需同步检查总预设的目录隔离和文件交接测试。
