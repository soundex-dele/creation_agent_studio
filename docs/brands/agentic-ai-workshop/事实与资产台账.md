## 产品录入模板

有真实产品后复制使用，一份产品一条记录。未填完整的内容标为草稿，不作为已上线产品推荐。

| 应用字段 | 应填内容 |
|---|---|
| 产品名称 name | 对外使用的准确名称 |
| 产品介绍 description | 面向谁、解决什么问题、具体交付什么 |
| 产品事实 facts | 一条一个可核验事实，例如课时、功能、交付形式、价格适用日期 |
| 来源说明 source | 官方页面、有效文档或由用户提供的确认信息，注明日期 |
| 使用限制 restrictions | 适用条件、依赖工具、服务边界、有效期等实际限制 |
| 禁止承诺 prohibited_claims | 没有证据的收益、效果、能力或时间保证 |

不要把「计划开课」「希望提供咨询」写为已经提供的产品。没有用户确认的商品，不创建虚构价格、名额、优惠或购买链接。

## 真实范文收录模板

| 应用字段 | 应填内容 |
|---|---|
| 名称 name | 原文标题；内部草稿在名称前加「草稿」 |
| 平台 platform | 实际发布平台，未发布则如实标注 |
| 正文 body | 已取得使用权限的原文；保留关键结构和原意 |
| 来源链接 source_url | 真实原始链接，无链接时留空，不编造 |
| 借鉴特点 highlights | 具体写法及适用场景，如「先呈现场景，再逐步解释操作」；记录来源和收录日期 |

内容手册中的新写示范尚未作为优秀范文入库。后续即使收录，也应标明「新写示范，未发布，无表现数据」。借鉴范文语气时，不继承原文中的产品事实、经历和效果数字。
