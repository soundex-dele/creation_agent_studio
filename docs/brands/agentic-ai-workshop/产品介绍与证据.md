# Agent Studio · 产品介绍与证据

产品与品牌关系由用户确认：当前项目是「智能体AI工坊」的工具产品。项目名称 Agent Studio 来自仓库 README 和登录页；正式对外商品名称待确认。

## 建议对外介绍

**一句话版**

Agent Studio 是智能体AI工坊的工具产品，把智能体、场景应用和工作流组织在同一个工作台中，帮助你围绕具体任务开展实践。

**面向创作者的介绍草稿**

做内容时，你需要反复说明账号定位、准备素材、写不同平台的文案，还要处理封面和排版。Agent Studio 围绕这些环节提供品牌资料库、文案创作、封面与排版等应用，也提供资料研究和工作流能力。你可以从一个具体任务开始，选择需要的应用，检查结果后再进入下一步。

产品能力以实际部署和配置为准；这段介绍不表示所有环节已自动连接，或能直接替你发布到平台。

## 品牌与产品如何相互支持

建议将关系表述为：「智能体AI工坊分享方法和案例，Agent Studio 承载其中适合的工具实践。」账号内容可覆盖其他工具；介绍自己的产品时明确关系，按同样的标准说明任务、步骤、结果和限制。

**优先演示主题建议：从一份品牌资料开始创作。**

1. 在品牌资料库保存定位和语气。
2. 在支持品牌引用的图文文案应用中，选择这份档案并补充本次主题。
3. 检查提示词预览是否带入正确资料，再发起创作。
4. 检查生成文案是否符合品牌表达，人工修改不准确或不适合的部分。

这个主题有应用配置和文档依据，适合后续实际录制；本次没有完成运行或录屏，不把它写成已经验证的案例。
