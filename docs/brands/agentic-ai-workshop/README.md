版本：v0.2｜建立日期：2026-09-28｜状态：可用首稿，含待确认建议；支持脚本迁移导入。

**建议核心定位：面向想动手实践的人，用搭建教程、案例拆解和工具测评，帮助他们把智能体用到具体任务中。**

## 从这里使用

| 文件 | 用途 |
|---|---|
| [品牌档案.md](品牌档案.md) | 查看账号定位、品牌语气与视觉规范；可按字段复制到项目的品牌资料库应用 |

| [product-agent-studio.json](product-agent-studio.json) | 一条可按字段录入的产品事实资料 |
| [内容手册.md](内容手册.md) | 栏目规划、候选选题、创作模板、文字示范和发布检查 |
| [事实与资产台账.md](事实与资产台账.md) | 区分已知事实与建议，维护产品、范文、素材和待补资料 |
| [AI创作上下文.md](AI创作上下文.md) | 给写作助手使用的精简品牌背景 |
| [迁移导入说明.md](迁移导入说明.md) | 使用脚本导入、预览、重复执行及更新已有资料 |

建议首次先读品牌档案，再用内容手册挑一个选题开始。单次创作时附上 AI 创作上下文，并补充本次真实素材、平台和目标。

## 五个模块的当前状态

| 应用模块 | 本次已准备 | 资料状态 |
|---|---|---|
| 账号定位 | 原始简介、精简简介、受众、平台、领域、价值与目标 | 名称、原始简介、受众和四个平台来自用户；策略为建议 |
| 产品事实 | Agent Studio 产品条目、介绍、证据与边界 | 产品归属由用户确认；能力根据项目文档与配置整理 |
| 品牌语气 | 风格、原则、推荐用语、禁用表达及正反例 | 建议规范，可用于首轮创作 |
| 优秀范文 | 内容手册中的语气示范、真实范文收录模板 | 尚无用户历史作品；示范不作为已验证范文 |
| 视觉规范 | 色彩、字体、封面、插图、署名建议 | 建议方案；未生成或确认 Logo |

## 录入项目内的品牌资料库

1. 在品牌资料库应用新建档案，名称填写「智能体AI工坊」。
2. 将品牌档案中的账号定位、品牌语气、视觉规范按同名字段填入。
3. 按 product-agent-studio.json 新增 Agent Studio 产品条目。优秀范文暂留空；取得真实作品后按台账模板新增。
4. 创作时按需引用：普通写作选账号定位＋品牌语气；封面或排版增加视觉规范；只有确实涉及某项产品或范文时才选择相应条目。

已于 2026-09-28 导入当前本地运行应用的 `admin` 账号，组织为 `Enterprise Workspace`：保存 1 份「智能体AI工坊」品牌档案及 1 条 Agent Studio 产品资料。已通过应用的用户范围读取接口逐字段核对提交后的内容；真实优秀范文仍待补充。导入记录见 [import-receipt.json](import-receipt.json)。

后续迁移可使用 [导入脚本](../../../backend/scripts/import_brand_library.py)，以 `import-manifest.json` 为清单导入全部资料。`brand-profile.json` 单独保存档案字段，产品和范文使用独立 JSON。操作命令与目标数据库配置见[迁移导入说明](迁移导入说明.md)。

## 维护方式

- `brand-profile.json` 是定位、语气和视觉字段的主文件；修改时同步更新可读版「品牌档案.md」。其他文件维护扩展内容，不覆盖主文件的事实状态。
- 对外事实记录来源和核验日期。工具版本、价格、功能或测评结论在发布前重新核对。
- 素材标注「用户已提供」「建议」「待补充」「已核验」；只有用户确认或证据核验后才更新状态。
- 品牌主张变化时升主版本；补充范文、修正字段或增加素材时升次版本，并在下面写一行记录。
