# 复用现有前后端，新增远程访问设置与“我的电脑”应用

状态：已实现，接口与部署说明见 `REMOTE_ACCESS_API.md`、`DEPLOYMENT.md`。

更新日期：2026-09-22。

本文保留实现范围和验收要求。现有前后端、独立连接进程、设备配对与转发、“我的电脑”入口均已接入；远程访问默认关闭。

## 方案概述

电脑端直接运行项目现有 React 前端、Django 后端及执行器，通过 **设置 → 远程访问** 开启连接。源码运行和现有桌面打包版共用这套能力。

手机登录服务器，打开“我的电脑”应用，选择已绑定的在线电脑进行对话。服务器负责转发，业务数据和任务执行都在电脑上。

```text
手机网页 / 移动端外壳
        ↕ HTTP API / SSE
现有服务器：账号、设备绑定、连接状态、数据转发
        ↕ 电脑主动建立的 WebSocket 连接
电脑端连接进程 → 本机 Django API → 现有执行器
                        ↕
              本地数据库、对话、事件与文件
                        ↕
                  本机 React 前端
```

## 电脑端：前端设置与后台连接

- 在现有系统设置页增加“远程访问”分组，包含服务器地址、电脑名称、启用开关、配对码、绑定账号、连接状态、重连和解绑操作。
- 配置通过本地后端 API 保存到本地数据库；凭证仅保存在后端，不进入浏览器存储。“重置界面偏好”不影响远程访问配置。
- 本地管理员配置连接，明确选择授权访问的本地用户和组织；远程操作沿用该用户的业务权限和许可证校验。
- 配对流程：电脑生成短期、单次有效的配对码，手机登录服务器后输入，电脑设置页确认绑定账号。每台电脑绑定一个服务器账号，一个账号可绑定多台电脑。
- 新增后端管理命令 `run_remote_connector`，复用项目依赖和虚拟环境。由本地启动脚本及桌面启动器管理，禁止在 Django 请求或模块初始化时临时启动后台线程。
- 连接进程启动后监听已保存配置；默认关闭，启用后主动连接服务器，配置变更无需重启整个后端。单实例锁防止重复连接。
- 关闭浏览器不影响连接；停止本地后端或连接进程后设备离线。关闭远程访问立即断开通道，保留绑定；解绑同时撤销凭证。
- 服务器部署默认不开启“作为受控电脑”的能力，设置页根据后端能力标识显示对应设置。

## 手机端：“我的电脑”应用

- 在现有应用中心注册 `my-computer` 专用应用，首页默认展示当前账号绑定的在线电脑；设备管理中可查看离线设备和解绑。
- 选择电脑后查看该电脑的历史对话，可新建普通对话、选择电脑上的对话应用或继续已有对话。
- 支持流式回复、停止任务、回答补充问题、允许或拒绝工具授权；应用、智能体和技能均从所选电脑加载。
- 复用聊天组件和 Run 事件投影，引入显式连接上下文；服务器和不同电脑的组织、应用、对话状态分别隔离，避免串用数据。
- 对话页显示电脑名称及在线、重连、离线状态，手机返回路径为“对话 → 对话列表 → 电脑列表”。
- 首版不包含附件传输、文件下载或远程桌面；已有附件显示名称和不可预览提示。

## 通信与接口

- 本地新增 `/api/v1/remote-access/` 配置、配对和连接状态接口；服务器新增 `/api/v1/remote/` 设备绑定、查询、撤销和转发接口。
- 电脑通过 `/ws/remote/connector/` 主动建立 WebSocket；手机沿用 HTTP API 和 SSE，服务器在二者之间转发。
- 电脑连接进程调用本机现有 API，复用 Conversation、Run、Coordinator 和 Command；服务器不为远程对话创建业务 Run。
- 转发采用版本化协议，支持请求标识、分块响应、结束、错误、取消订阅和心跳。每 20 秒心跳，60 秒无响应标记离线，断线后退避重连。
- 生产环境支持 Redis Pub/Sub 跨进程临时转发，或显式启用无 Redis 的单 ASGI 进程内存转发；正文不写入数据库、持久队列或日志。服务器仅保存账号、设备绑定及连接元数据。
- 服务器与电脑同时检查接口白名单；只开放必要的对话、应用读取和 Run 操作，不提供任意 URL 转发。本地凭证不发送到服务器。
- 复用发送消息及任务命令的幂等机制，为新建对话补充本地幂等支持；响应丢失后用原幂等键恢复，避免重复执行。
- 重连后按事件序号补取，兼容历史压缩后的快照地址；分页和快照请求始终经过同一电脑通道。
- 手机断线或退出页面仅结束订阅，不停止电脑任务。电脑离线时禁止发送并保留当前页面草稿，服务器不暂存指令。
- 双端打开同一对话时，空闲页面每 5 秒刷新状态，发现活动 Run 后订阅事件流，使另一端发起的任务也能显示。

- 使用项目虚拟环境完成后端测试及应用包校验，完成前端相关测试、类型检查和生产构建；不使用 Codex 内置浏览器。

- 默认不增加端到端加密，沿用部署站点的 HTTP/HTTPS 与 WS/WSS；不增加组织共享、离线排队、远程唤醒或开机自启。
